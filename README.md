# 🤖 Eridan Forge — кружок робототехники и веб-разработки

**Живая ссылка:** https://eridan-forge.github.io/eridan-forge-site/ROBOT-SITE/

## О проекте

Это сайт-визитка моего кружка, где я учу детей и подростков:
- Собирать и программировать роботов (Arduino, C++)
- Создавать сайты с нуля (HTML, CSS, JavaScript)

Сайт сделан в учебных целях, но полностью рабочий. Показывает мои навыки во frontend-разработке.

---

## Технологии

- HTML5
- CSS3 (Flexbox, Grid, адаптив, анимации)
- JavaScript (модальные окна, выезжающее меню, маска телефона)
- Google Fonts (Playfair Display, EB Garamond)
- GitHub Pages (хостинг)

---

## Функции сайта

- ✅ Адаптивный дизайн (телефон/планшет/ПК)
- ✅ Выезжающее меню
- ✅ Модальное окно с выбором страны и маской телефона
- ✅ Анимированная сетка на первом экране
- ✅ Плавный скролл к якорям
- ✅ Форма обратного звонка
- ✅ Расписание занятий
- ✅ Контакты и соцсети
